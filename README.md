# Anki学習カード作成 Skills

教材メモの校正から、Ankiに読み込める一問一答・4択カードの作成までを支援するエージェントSkill集です。試験ごとに作業フォルダを分け、同じ手順を繰り返し使えるようにしています。

## Skills

| Skill | 用途 |
| --- | --- |
| `anki-course-pipeline` | 校正、一問一答、4択を順に実行する一括処理 |
| `anki-source-proofreading` | 参照資料に基づく学習メモの校正と用語集作成 |
| `anki-import-file` | 一問一答のAnkiインポートファイル作成 |
| `anki-import-four-choice` | 4択のAnkiインポートファイル作成 |

Skillの定義は`.agents/skills/`にあります。このリポジトリを開いた対応エージェントから利用できます。

## 試験ごとの作業フォルダ

試験ごとに`target-folder/`直下へフォルダを作ります。以下の各ディレクトリは、試験フォルダからの相対パスです。

```text
target-folder/
├── .gitignore
└── <exam-slug>/
    ├── input/       # 校正・カード化する学習メモ
    ├── Reference/   # 参照する教材やPDF
    ├── Exam-Guide/  # 任意の試験範囲資料
    ├── output/      # Ankiファイル、用語集
    └── Done/        # 一括処理が完了した入力資料
```

`Exam-Guide/`は任意です。指定した試験フォルダだけを処理し、複数の試験を混ぜないでください。

## 使い方

1. 使用する試験フォルダの`input/`に学習メモを置きます。
2. 根拠として確認する資料を`Reference/`に置き、必要なら試験範囲資料を`Exam-Guide/`に置きます。
3. エージェントに試験フォルダと章・範囲を指定して依頼します。一括処理では、校正、一問一答、4択の順で進みます。
4. 作成されたファイルと用語集を`output/`で確認します。一括処理では、各工程と成果物の確認が完了した入力資料を`Done/`へ移します。

一問一答または4択だけを作る場合は、それぞれ`anki-import-file`または`anki-import-four-choice`を指定できます。校正だけの場合は`anki-source-proofreading`を指定します。

## Ankiファイル形式

インポートファイルはUTF-8のタブ区切りテキストです。先頭に`#separator:tab`、`#html:true`、`#guid column:1`を指定し、各ノートを「GUID・表・裏」の3列で出力します。

既存ノートを再生成・更新するときは、同じ範囲の前回の`output/`ファイル、またはGUID付きのAnkiエクスポートをエージェントに渡してください。`output/`はGit管理対象外なので、新しく複製した作業環境にはありません。対応するGUIDを確認できない場合、そのノートの更新を進めません。

## Git管理と公開

リポジトリルートと`target-folder/`直下の`.gitignore`で、すべての試験フォルダを無視します。新しい試験フォルダも自動的に対象となり、実際の試験フォルダ名とその中身はGitHubに公開されません。公開対象として追跡するのは`target-folder/.gitignore`だけです。

`target-folder/.gitignore`の内容は次のとおりです。

```gitignore
*
!.gitignore
```

`.gitignore`は、すでにGitで追跡しているファイルには効きません。公開前にステージ済みファイルとGit履歴を確認し、教材や個人情報を含むファイルが公開対象に残っていないことを確認してください。教材PDFや第三者の資料を公開する場合は、再配布できることを事前に確認してください。

Skillやドキュメントでは、端末固有の絶対パスやユーザー名を使わず、リポジトリ内の相対パスを使います。
