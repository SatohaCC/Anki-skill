# 参照資料に基づく学習メモの校正

指定された学習メモや文字起こしを、ユーザーが示した教材・PDFを根拠に校正する。依頼範囲のファイルだけを編集し、元資料の意味、情報量、順序、強調を保つ。根拠のない説明や事実を追加しない。

## 教材フォルダの読み取り先と出力先

リポジトリの`target-folder/`直下に試験ごとのフォルダがある場合、選択した試験フォルダ（`target-folder/<試験slug>/`）を教材フォルダとして扱い、その配下に次の構成を使う。ユーザーが`target-folder/`だけを指定した場合は依頼された試験に一致するフォルダを選び、見つからない、または候補が複数ある場合は確認する。試験フォルダや個別ファイルが明示された場合はその指定を優先し、別の試験フォルダを横断しない。

- `input/`：校正対象の学習メモや文字起こし。
- `Reference/`：校正根拠となる教材PDFなど。
- `Exam-Guide/`：任意。試験ガイド、試験ドメイン、出題範囲などの資料がある場合だけ読む。フォルダが空、または存在しなくても作業を続ける。
- `output/`：用語集など、このスキルが作成する成果物。
- `Done/`：問題作成済みのinput資料。

ここに記載した各フォルダ名は、すべて選択した試験フォルダからの相対パスである。Skill、生成ファイル、実行報告にマシン固有の絶対パス、ユーザー名、ホームディレクトリを含めず、報告では試験フォルダまたはリポジトリルートからの相対パスを使う。

ユーザーが特定のファイルを示した場合は、その指定を優先する。特定がない場合は指定された教材フォルダの`input/`から依頼対象を選び、`Reference/`から対応する参照資料を探す。Exam-Guideは校正対象の用語や試験範囲を把握する補助資料として使い、記述の正誤は参照教材で確認する。校正対象のメモは指定された`input/`内で修正する。`input/`や`Reference/`に用語集などの成果物を新規作成しない。

## 手順

1. **対象と形式を確認する**
   - 対象ファイル、参照資料、依頼範囲を確認する。適用される AGENTS.md などの指示と、既存の用語集があれば内容も読む。
   - 元ファイルの文字コード、改行、Markdown構造、Ankiインポート形式を把握する。参照PDFは編集せず、ユーザーが校正対象として指定したファイルだけを編集する。

2. **参照資料で表記を確かめる**
   - PDFのテキスト抽出で該当語句やページを探す。抽出文字が崩れている場合、表・図・数式・レイアウトが判断に関係する場合は、該当ページを画像で確認する。
   - 専門用語、製品名、略語、数式、数値は資料中の表記と文脈を確認してから直す。用語の揺れは、ユーザー指定の参照資料に合わせる。
   - PDFの分解が必要なら、ページ画像や分割PDFをファイルとして残してよい。必要なものに限り、対象ファイルの近くかユーザー指定の場所に pdf-pages/ などの分かりやすいフォルダを作る。元PDFを上書きせず、作成した分解ファイルの場所を最後に報告する。
   - 参照資料が裏付けない箇所や、資料と対象文の食い違いを確信を持って解決できない箇所は、推測で書き換えず保留点として記録する。

3. **文章を校正する**
   - 資料で確認できる誤字、誤変換、専門用語の表記を修正する。固有名詞の英字大小、記号、句読点も一貫させる。
   - 行幅による不自然な改行は、段落の意味を保って整える。見出し、箇条書き、表、数式、コード、カードのフィールド境界など、意味のある区切りは維持する。
   - 文体や語尾の揺れを整え、読みやすくする。内容や主張の追加・省略、難易度の変更、用語の独自な言い換えはしない。
   - Anki用のタブ区切りTXTなどは、列数、タブ、HTML、フィールド順などのインポート構造を壊さない。

4. **用語集をファイル出力する**
   - 教材フォルダ構成を使う場合は`output/用語集.md`に作成する。`output/`がなければ作成する。既存の用語集がある場合は読み、無関係な項目を消さずに更新・追記する。
   - 教材フォルダ構成がない場合は、ユーザー指定の出力先を優先し、指定がなければ対象ファイルと同じフォルダ（複数フォルダなら共通の親フォルダ）に作成する。
   - 表には「用語」「推奨表記」「概要」「参照元（資料名・ページ）」を含める。本文に登場する重要語と、校正で表記を直した語を中心に、短く資料に沿って記載する。
   - 略語は正式な英語表記（フルスペル）と日本語表記・意味を記載する。正式名称が確認できない場合は推測せず、その旨を示す。
   - 概要やページ番号を確認できない用語は断定して埋めず、根拠不足として扱う。

5. **確認して報告する**
   - 変更後のファイルを読み直し、誤修正、文の欠落、改行の崩れ、用語の不統一、インポート形式の破損がないか確認する。
   - 最後に、編集したファイル、修正の種類、参照した資料とページ、用語集の出力先、分解ファイルを残した場合はその場所、判断を保留した点を簡潔に報告する。
